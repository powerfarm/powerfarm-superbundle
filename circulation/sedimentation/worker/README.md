Private Cloudflare Service Binding setting for `pf.reconciler.sedimentation`.

It binds the portable controller to Registry, Evidence, Imagineering and Process. It has no public operational HTTP route.

The Worker does not hold:

- capability definitions;
- implementation artifacts;
- work profiles;
- candidate assessments;
- construction state;
- transition proposals;
- promotion authority.

All of those remain behind their owning organ ports. The Worker may evaporate between passes.

Deploy it before admitting a Heartime reconciliation contract whose:

```text
reconciler_ref = pf.reconciler.sedimentation
resource_hint  = a CapabilityLearningScopeRef
```
