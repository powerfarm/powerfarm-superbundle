**Permanent portable core:** built and verified.

This seam makes Canon §9.4 executable without making Organism the owner of capability state.

```text
Heartime notices
  ↓
Sedimentation Reconciler reads current organ-owned state
  ↓
Evidence profile says stable / uncertain / contradicted
  ↓
Imagineering receives construction or evaluation responsibility
  ↓
Process receives a succession proposal
  ↓
Registry changes occupancy only after promotion
```

The reconciler is deliberately unable to activate, promote, rewrite or delete a capability implementation. It can only ensure idempotent obligations through versioned owner ports.

## Digital-only law

`inference`, `configuration`, and `fixed` are digital execution substrates. The CPU/FPGA/ASIC language in Canon is analogy, not a physical deployment requirement.

## Admission facts

A transition is eligible only from independently observed assessment values. Candidate forecasts may guide construction, but cannot prove savings, quality, latency, uncertainty, or cognition reduction. Every proposal binds the exact source occupancy, implementation revisions, target substrate, target cognition fraction, and fallback lineage.
