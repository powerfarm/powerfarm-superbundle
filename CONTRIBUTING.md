Start with `README.md`, `DOCUMENTATION.md`, `canon/README.md`, and `contracts/README.md` before editing code.

Changes must preserve these boundaries: Registry owns institutional identity reality; Process owns Authority/admission/consequence; Cards are the circulation carrier; Heartime owns circulability/liveness rather than Authority; engines never define PowerFarm institutional meaning.

Do not edit `engines/ai-sdk/upstream/` to encode PowerFarm semantics. Update engine pins deliberately and make any GitHub-distribution omissions explicit.

Before opening a pull request run:

```sh
npm run github:check
npm run verify
```

Python Process tests require the dependency set described in `.github/workflows/verify.yml`.
