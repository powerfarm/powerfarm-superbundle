The Organism owns these contracts, not the state behind them.

## Registry

`powerfarm.registry.capability-learning.v1`

```text
resolveCapabilityLearningScope
findCapabilityImplementationCandidate
```

Registry owns durable capability identity, revisions, implementations, occupancies, fallback lineage and learning policy.

## Evidence

`powerfarm.evidence.capability-learning.v1`

```text
profileCapabilityWorkClass
assessCapabilityImplementation
recordCapabilityLearningEvidence
```

Evidence owns measured execution profiles and independent equivalence assessments. A model-written description is not a profile.

## Imagineering

`powerfarm.imagineering.capability-construction.v1`

```text
ensureCapabilityConstruction
ensureCapabilityEvaluation
```

Imagineering owns provisional construction and evaluation responsibilities. The reconciliation controller cannot construct or certify its own candidate.

## Process

`powerfarm.process.capability-succession.v1`

```text
ensureCapabilityTransitionProposal
```

Process owns the proposal and promotion path. Ensuring a proposal does not activate it.

## Reconciler

`powerfarm.sedimentation.reconciler.v1`

```text
reconcile
```

Heartime supplies only `BeatRef`, `ReconcilerRef`, reason, and `CapabilityLearningScopeRef`. The result is a compact reference-only summary.
