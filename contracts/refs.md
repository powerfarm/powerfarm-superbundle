**Status:** permanent First Seam support contract

PowerFarm identities are not network locations.

```text
pf.card.market-change       institutional identity
https://worker.example/...  transport address
CARDS service binding       provider-local mechanism
```

The First Seam carries institutional references across every boundary:

```text
BeatRef
ReconcilerRef
CardRef
WakePackRef
OfficeRef
OccupancyRef
AttemptRef / RunRef
EvidenceRef
ContractRef
```

A reference MUST NOT be replaced by a preview URL, Worker name, database primary-key path, queue topic, or provider-specific resource name.

Provider bindings resolve or transport institutional references. They do not define them.

The v1 source validator rejects HTTP(S) values where an institutional reference is required.
