For an LLM or coding agent entering this repository:

1. Read `README.md` and `DOCUMENTATION.md` to locate the organ or boundary you are changing.
2. Read `canon/README.md` for institutional meaning and `contracts/README.md` for executable promises.
3. Treat Cards as the canonical circulation carrier and Heartime as circulation/liveness enforcement, never as an Authority source.
4. Treat Process as the owner of Authority, admission, run consequence and execution custody.
5. Treat Registry as a separate repository and the source of Identity, Office/Occupancy and keys.
6. Never encode PowerFarm ontology inside an upstream engine. `engines/ai-sdk/upstream/` is third-party source.
7. Run the narrowest relevant tests while editing, then `npm run verify` and `npm run github:check` before completion.
8. Do not persist raw chain-of-thought. Preserve evidence, observations, claims, uncertainty and provenance through the institutional contracts instead.
