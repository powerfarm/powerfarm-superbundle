Report security vulnerabilities privately through GitHub Security Advisories for this repository. Do not open a public issue for credentials, authorization bypasses, identity/occupancy takeover, replay of external effects, or evidence-integrity failures.

The repository must never contain production credentials, private signing keys, service-role secrets, live `.env` files, or raw chain-of-thought. Runtime credentials are short-lived operational credentials and never institutional Authority.
